# Widget

Widget reads its own config. The tool reads a file. It splits the text into sentences. It checks
each sentence against the rules. It prints a report. It exits with a code. The report names the
file. It lists each place.

It checks the project's own docs. A person reads the report. The person fixes the text. The tool
runs again. The second run is clean. The build waits for the tool. The tool needs no network.

The users keep their own data. It reads the config from the repo. The config lists the globs. Each
glob selects some files. The files are plain text. Some are Markdown.
