# Widget

A comma:

Parent nodes should summarize their children's responsibilities, not duplicate their details.

A comma and `never`:

Is stored in the device's secure keychain, never in plain storage.

A semicolon:

Model fallibility with `Result<T, E>` and `Option<T>`; never paper over it.

An em dash:

Fill in the note with something specific to what they actually said — never leave it as a generic placeholder.

A spaced hyphen:

Use this component on the element that requires truncation - not on a parent element.

Closing markup after the tail:

**Slices land behind their own tests, not a big-bang rewrite.**

A comma that a `not` follows stays in the tail, and the last denial is the one that ends the sentence:

Reports are written only by the CLI/campaign entry, never by the pure planner/scorer; the path is repo-relative; a test writes to a temp dir, not the repo.

A colon or a semicolon after the tail ends a line of a list and still ends the sentence:

It has no `COPY` instruction, so use a small build context (the `docker/rocm` directory), not the repository root:

methods extended from other modules must follow their inherited argument order, not the above rule;

A code span counts as its words:

Before every commit: `git status`, stage ONLY the files this task touched (path-scoped `git add`), never `git add -A`.

Link text counts as words, and the destination does not:

[Google App Engine requires](https://cloud.google.com/sql/docs/postgres/connect-app-engine) to connect to the database using the unix socket path, not an IP and port.
