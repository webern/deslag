## Marks on words

Some words in the numbered sentences carry a mark in braces glued to the word, such as
`foo_bar{symbol}`. A script added the mark, not a person. It says where the word seems to come from.
It is a hint about the word's use and never a tag. The marks are:

- `{symbol}`: a name from code written as one, such as `foo_bar`, `userId`, `FrobulatorFactory`.
- `{command}`: the name of a program, or a git subcommand right after `git`, such as `grep`.
- `{path}`: a file name with an extension, such as `main.rs`.
- `{flag}`: a word joined to a leading `-` or `--`, such as the word in `--locked`.

The mark is not a token and has no number of its own. Tag the word as if the mark were not there, and
never write the mark in your answer. Section 4 of the guide, on identifiers outside code spans,
covers most of these words. A marked word that is an ordinary word in its ordinary sense in this
sentence keeps its ordinary tag (`grep the logs`: `grep` is a verb).
