# Widget

Widget reads its own config. The project's own docs say its own rules apply to their own users. The
tool reads a file. It splits the text into sentences. It checks each sentence against the rules. It
prints a report. It exits with a code. The report names the file.

The users' own data stays with them. Each module's own budget is checked. It lists each place. A
person reads the report. The person fixes the text. The tool runs again. The second run is clean.
The build waits for the tool.

Our own tests run first. The tool needs no network. It reads the config from the repo. The config
lists the globs. Each glob selects some files. The files are plain text. Some are Markdown. Some are
source code. The tool reads their comments. A comment is prose too. The tool skips the code.
