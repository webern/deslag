# Widget

The tool reads a file. It splits the text into sentences. It checks each sentence against the rules.
It prints a report. It exits with a code.

Widget reads its own config and writes the project's own docs. The report names the file. It lists
each place. A person reads the report. The person fixes the text.

Each module's own budget is checked. The tool runs again. The second run is clean. The build waits
for the tool. The tool needs no network. It reads the config from the repo.

The users' own data is left alone. The config lists the globs. Each glob selects some files. The
files are plain text. Some are Markdown. Some are source code. The tool reads their comments. A
comment is prose too. The tool skips the code.

It never edits a file. It only reads. The report is for an agent. The agent reads it on stderr. The
agent knows what to do next. A clean run prints nothing. A failing run prints one report per file.
Each report has a heading.
